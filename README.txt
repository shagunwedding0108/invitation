#SHAGUN — Gunjan & Akshay | Website V7

OPEN THE WEBSITE
1. Extract the entire ZIP.
2. Open index.html in Chrome, Edge, Safari or another modern browser.
3. Tap "Enter Our Wedding" to begin the chosen recording.

WHAT'S NEW IN VERSION 7
- Your uploaded recording "Tum Prem Ho · Tum Preet Ho" is now the wedding soundtrack.
- The original user-uploaded WebM/Opus recording was converted to MP3 for
  wider compatibility. The full ~5:02 audio, including its spoken ending,
  has been retained without editing.
- Playback starts only after the Enter button is tapped. Browsers block
  music from starting without a gesture, so this is intentional.
- A floating soundtrack player permits play/pause, mute, volume, seek and
  optional repeat. Looping is off by default.
- The previously generated engagement illustration, all six photographs,
  all five immersive celebration scenes, English/Hindi, calendar reminders,
  WhatsApp sharing, maps and PDF are retained.

PUBLISHING
Deploy this folder to a static host such as GitHub Pages or Netlify.
The site uses no RSVP backend. The Send Your Wishes form is still only
an on-device preview, not an actual shared guestbook.
IMPORTANT: Before publishing with a commercial song recording, confirm
that you have permission or any necessary license for public streaming.
You can change the audio by replacing assets/tum-prem-ho-tum-preet-ho.mp3.

SINGLE FILE VERSION
The alternative V7 Single_File.html embeds the MP3, images, illustrations,
scene art and invitation PDF and works without extracting the ZIP, though
it is larger and may open more slowly. Fonts still use Google Fonts online,
falling back to installed system fonts if unavailable.
